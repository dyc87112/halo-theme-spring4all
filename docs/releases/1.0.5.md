# 春野主题 1.0.5

统一各页面主体宽度，并增加可集中管理的谷歌广告配置。

- 首页、文章、分类、标签、归档、作者、独立页面和瞬间使用统一的主体宽度与响应式边距。
- 谷歌广告支持五个位置：首页列表上方、首页侧栏、文章正文上方、文章目录下方、文章末尾。
- 设置按公共设置、文章页广告和首页广告分组，每个位置使用独立卡片，全部展开。
- 各位置独立配置开关、广告单元 ID、格式与移动端显示，保留此前目录广告的配置键。
- 多广告位共用 AdSense 脚本，仅初始化可见单元；空广告或加载失败时收起对应位置。

主题默认不包含广告账号和广告单元 ID，广告总开关默认关闭。安装后在主题设置 → 谷歌广告中填写自己的参数；正式投放时关闭布局预览模式。

兼容 Halo >= 2.26.0，本地验证使用 Halo 2.26.1。将本次发布的 `theme-spring4all-1.0.5.zip` 上传至 Halo Console → 主题 → 安装 / 升级。主题内部标识仍为 `theme-spring4all`。
